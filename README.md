
# 🔐 Elevate Labs Cybersecurity Internship — Project Submission

This repository contains the final projects completed as part of my **Cybersecurity Internship at Elevate Labs**.

The projects demonstrate practical implementation of cybersecurity concepts including **log analysis, intrusion detection, secure file storage, encryption, and data integrity verification**.

---

## 📂 Projects

### 1. 🔎 Log File Analyzer for Intrusion Detection

A Python-based security tool that analyzes web and authentication log files to identify suspicious activity and potential intrusion attempts.

#### Key Features

- Parses access and authentication logs
- Detects suspicious IP addresses and attack patterns
- Analyzes HTTP status codes and requests
- Generates incident reports
- Creates graphical visualizations of log activity
- Helps identify potential intrusion indicators

#### Technologies Used

- Python
- Pandas
- Matplotlib
- Log Analysis
- Intrusion Detection

📁 **Project Folder:** `Project-1-Log-File-Analyzer`

---

### 2. 🔐 Secure File Storage with AES

A Python-based secure file storage system that uses Fernet symmetric encryption to protect files and SHA-256 hashing to verify file integrity and detect tampring.

#### Key Features

- Secure file encryption and decryption
- Fernet symmetric encryption for secure file protection
- SHA-256 integrity verification
- Metadata management
- Detection of file tampering
- Command-line interface

#### Technologies Used

- Python
- Cryptography
- Fernet symmetric Encryption
- SHA-256
- JSON
- File Integrity Verification

📁 **Project Folder:** `Project-2-Secure-File-Storage`
